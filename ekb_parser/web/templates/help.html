{% call topic('saved-run', 'Сохранённый сбор') %}

Выберите папку уже запущенного сбора. Этот выбор действует на страницах результатов, компонентов и журнала.

Чтобы продолжить обход, откройте страницу «Сбор каталога». Настройки подставятся из выбранного сбора. Нажмите «Запустить сбор».

{% endcall %} {% call topic('preset', 'Как выбрать категорию') %}

Категория объединяет подкатегории с одного сайта. Например, в «Конденсаторах» есть алюминиевые и керамические конденсаторы. Все подкатегории одной категории хранятся в одном файле конфигурации.

{% endcall %} {% call topic('subcategory', 'Как выбрать подкатегорию') %}

Выберите одну подкатегорию, чтобы собрать только её. Пункт «Все подкатегории» запускает обход каждой подкатегории по очереди.

Точные фильтры выбранной подкатегории видны в дополнительных настройках.

{% endcall %} {% call topic('max-pages', 'Лимит страниц') %}

Сколько страниц каталога обработает парсер за этот запуск. Введите 0, чтобы снять ограничение по страницам. Сбор остановится по лимиту компонентов или в конце выборки.

Пример. Две страницы по 100 строк дают до 200 записей за запуск.

{% endcall %} {% call topic('max-parts', 'Лимит компонентов') %}

Сколько уникальных компонентов максимум может хранить выбранный сбор. Уже сохранённые записи входят в это число.

Пример. Если в сборе уже 200 компонентов, лимит 300 позволит добавить ещё до 100.

{% endcall %} {% call topic('page-size', 'Строк на странице') %}

Сколько строк парсер запрашивает у сайта за раз. Для YAGEO можно выбрать от 1 до 100. При продолжении используйте размер страницы из сохранённого сбора.

{% endcall %} {% call topic('delay', 'Пауза между запросами') %}

Минимальная пауза между запросами к сайту в секундах. Для обычного запуска оставьте 2. Увеличьте паузу, если сайт ограничивает частоту запросов.

{% endcall %} {% call topic('mode', 'Режим запуска') %}
С нуля
Создаёт новый сбор. Укажите отдельную папку внутри data/.
Продолжить
Берёт сохранённый прогресс и запрашивает следующие страницы. Можно поменять лимиты и задержку. Фильтры и размер страницы должны совпадать с прежними.
{% endcall %} {% call topic('output', 'Папка результата') %}

Это путь относительно корня проекта. Можно оставить предложенный путь, например data/yageo/runs/resistors-1606_20261118_101232.

В папке хранятся рабочий SQLite, настройки, выгрузки и скачанные PDF. Чтобы продолжить, проще выбрать эту папку в верхнем списке сохранённых сборов.

{% endcall %} {% call topic('groups', 'Группы и фильтры') %}

Поле принимает JSON-массив. У каждой группы есть уникальный key латиницей, name для интерфейса и объект query с фильтрами сайта.

Пример для толстоплёночных резисторов YAGEO
[
  {
    "key": "resistors-1606",
    "name": "Толстоплёночные резисторы",
    "query": {"1": 1605, "79": [1606]}
  }
]

У YAGEO 1 — ID категории, 79 — фильтр по типу. Доступные значения можно проверить на странице «Источники».

{% endcall %} {% call topic('adapter-options', 'Настройки адаптера') %}

Поле принимает JSON-объект. Оставьте {}, если готовый пресет не требует дополнительных настроек.

Для новой категории YAGEO пресет из URL может задать catalogue_category. Это название раздела в адресе карточек товара. При продолжении сбора сохраните настройки из его конфигурации.

{% endcall %} {% call topic('no-export', 'Когда создавать выгрузки') %}

С включённой галочкой парсер сохраняет данные и прогресс в SQLite. CSV и JSONL можно сформировать позже кнопкой «Создать выгрузки» на странице «Результаты». Для длинного сбора это сокращает работу после каждого запуска.

{% endcall %} {% call topic('pdf-limit', 'Лимит загрузки PDF') %}

Лимит действует только на этот запуск загрузки. Введите 0, чтобы обработать все ссылки, по которым ещё нужен PDF.

Уже сохранённые файлы пропускаются, прошлые ошибки могут быть повторены. Один и тот же PDF может относиться к нескольким артикулам.

{% endcall %} {% call topic('coverage', 'Как считается заполненность') %}

Оценка показывает, сколько обязательных полей заполнено по матрице аналитиков. Значения берутся из каталога, матрицы и импортированных дополнений.

Пример. Если у резистора заполнены 3 из 9 полей, его оценка — 33,3%. Для сбора делим сумму заполненных полей на сумму обязательных полей по всем оценённым артикулам. Компоненты без подходящей группы показаны отдельно.

Отчёт JSONL содержит одну строку на артикул, список полей, их значения и источники. Его можно передать коллеге как список того, чего не хватает.

{% endcall %} {% call topic('supplements', 'JSON с дополнениями из PDF') %}

Загрузите один файл .json с массивом записей. В верхней панели выберите сбор, из которого взяты идентификаторы. Большие пакеты можно разбить на файлы до 32 МБ.

Пример для резистора AA0402FR-134K75L
[
  {
    "source": "yageo",
    "source_id": "33810302",
    "fields": {
      "Tмн, ч": {
        "value": 20000,
        "evidence": "Отчёт по серии AA, стр. 4"
      }
    }
  }
]

Значение и источник в примере условные. Подставьте данные из документа.

source, source_id
Источник и ID записи сайта. Скопируйте из parts.jsonl или отчёта о заполненности. source_id пишите в кавычках.
fields
Имена полей копируйте из отчёта. Укажите value в единицах поля и evidence с именем или URL документа и страницей. Если данных нет, пропустите поле.
group
Необязательная пара ["Лист", "Подгруппа"]. Нужна, если требуется уточнить классификацию. Имена должны совпадать с матрицей.

Исходные файлы — HTML-листы из project_files/analytics_data/. После обновления листов нажмите «Обновить из HTML». Будет собран data/analytics/requirements.json.

+

−

{% endcall %} {% call topic('filter-group', 'Фильтры выбранной группы') %}

Выберите категорию и одну подкатегорию. Кнопка «Получить фильтры» запросит доступные параметры и значения для этой выборки. Полный ответ можно скачать в JSON.

Для настройки нового запроса используйте parameterId и id из parameterValues. Например, "79": [1606] выбирает толстоплёночные резисторы.

{% endcall %} {% call topic('preset-category', 'Выбор или создание категории') %}

Выберите существующую категорию, чтобы добавить подкатегорию в её файл. Для нового раздела YAGEO выберите «Создать новую категорию…» и укажите данные первой подкатегории в той же форме.

Название категории
Подпись в выпадающем списке, например Индуктивности.
Ключ категории
Имя файла. Например, ключ inductors создаст configs/yageo/inductors.json. Используйте строчные латинские буквы, цифры, дефис и подчёркивание.
{% endcall %} {% call topic('catalogue-mapping', 'Как найти ID параметра') %}
  1. Откройте ячейку матрицы и выберите подкатегорию. Справа появятся её параметры. Найдите нужный по названию или ID и нажмите на строку, чтобы подставить ID и название в форму. Если список пуст, нажмите «Получить фильтры».
  2. Если нужного параметра нет среди фильтров, откройте таблицу компонентов на YAGEO. В DevTools → Network → Fetch/XHR обновите страницу, откройте ответ запроса base-part и найдите параметр в массиве parameterValues конкретного артикула.
  3. Скопируйте parameterId, проверьте смысл параметра по описанию или datasheet и сравните value с formattedValue, чтобы определить единицы исходного числа.

Переключайте листы вкладками над таблицей. Панель можно прокручивать колесом или перетягивать мышью. В строках находятся группы аналитиков, в столбцах — поля. Зелёным показаны сохранённые сопоставления и значения из матрицы. Нажмите на обязательную ячейку и выберите подкатегорию каталога, чтобы добавить или изменить правило.

{% endcall %} {% call topic('mapping-factor', 'Перевод значения в единицы матрицы') %}

Множитель применяется к исходному числовому значению value. Например, при исходном значении в мА и поле матрицы в А задайте 0.001. Для текстовых значений и чисел в нужных единицах оставьте 1.

Сравните исходное число и отформатированное значение. Например, value: 0.25 и подпись 250 mA означают, что исходное число уже в амперах.

{% endcall %} {% call topic('preset-name', 'Название и ключ подкатегории') %}
Название
То, что увидите в выпадающем списке. Например, Толстоплёночные резисторы.
Ключ
Уникальный идентификатор подкатегории внутри её файла. Разрешены латинские буквы, цифры, дефис и подчёркивание. Например, resistors-thick-film.
{% endcall %} {% call topic('preset-catalogue', 'Адрес категории YAGEO') %}

Скопируйте адрес из строки браузера на странице нужной категории или подтипа.

https://yageogroup.com/products/Resistors?79=1606

Для новой категории из этого адреса программа берёт раздел каталога для ссылок на карточки. У существующей категории раздел уже задан.

{% endcall %} {% call topic('preset-request', 'Адрес запроса base-part') %}
  1. Откройте категорию YAGEO и примените нужный фильтр.
  2. Откройте DevTools → Network → Fetch/XHR и обновите страницу.
  3. Найдите запрос base-part и скопируйте его полный Request URL.

Подойдёт полный адрес или путь, начинающийся с /search/query/base-part/. Приложение декодирует JSON автоматически и сохраняет идентификатор категории 1 и все фильтры. Кнопка «Проверить запрос» покажет этот JSON до сохранения. Параметры сортировки и пагинации из ссылки отбрасываются. Сохранение проверяет совпадение идентификатора с выбранной существующей категорией.
